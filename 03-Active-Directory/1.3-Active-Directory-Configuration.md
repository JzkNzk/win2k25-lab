# Configuring your Active Directory server

## Goals

The goal of this lab is to organize an Active Directory environment by creating Organizational Units (OUs), user accounts, and security groups.

By completing this lab, you will learn how to:

- Create and organize Organizational Units (OUs) to structure domain objects.
- Create separate OUs for users, servers, workstations, groups, and service accounts.
- Create domain user accounts for different departments.
- Create Global Security Groups and Domain Local Security Groups.
- Add users to security groups to manage group membership.
- Verify the created users, groups, and OU structure using Active Directory Users and Computers.
- Log in to a Windows 11 client using a domain user account.

At the end of this lab, you will have a structured Active Directory environment with departmental user accounts and security groups, ready for centralized user and permission management.

## Configuring Organizational Unit structure

In this lab, we will use following Organization Unit structure for our Active Directory:
```
<domainName>
├── Users
│   ├── IT_Users
│   ├── HR_Users
│   ├── Sales_Users
│   └── Admin_Users
├── Servers
│   ├── App_Servers
│   ├── DB_Servers
│   └── Web_Servers
├── Workstations
├── Groups
└── ServiceAccounts
```

To create OUs, open your **Server Manager**, click on the *Tools* dropdown menu and select **Active Directory Users and Comupters**.

From there, in the left menu right-click you `<domain.name>` entry, select *New* and then *Organizational Unit*.

## Configuring Groups

In this lab, we will create two types of groups. One will be Global Group and the other will be Domain Local Group.

Each type will consist of 3 more groups.
Global Groups:
- IT Group - GG_WINAD_IT_Users
- HR Group - GG_WINAD_HR_Users
- Sales Group - GG_WINAD_Sales_Users

Domain Local Groups
- IT Group - DL_WINAD_FileShare_IT_RW
- HR Group - DL_WINAD_FileShare_HR_RW
- Sales Group - DL_WINAD_FileShare_Sales_RW

To create new group, navigate into `<domainName> > Groups` and right-click group folder. Select *New* and *Group*.

To add user to a group, navigate into `<domainName> > Users`, select user OU and from the list right-click your user and select *Properties*.

<img width="975" height="774" alt="image" src="https://github.com/user-attachments/assets/1c36c494-47e1-4747-81b8-11fdc106cf31" /><br>

Once you enter your Group click OK. The new group is now visible in the *Member of* list.
