# Basic overview of GPO configuration 

## Goals

The goal of this lab is to learn how to configure and manage Group Policy Objects (GPOs) in an Active Directory environment and apply different policies to selected users and computers.

By completing this lab, you will learn how to:
- Create and configure new Group Policy Objects using Group Policy Management.
- Configure user-based policies to restrict access to specific Windows features.
- Apply a GPO to a selected Organizational Unit (OU) containing user accounts.
- Configure computer-based policies, such as a legal notice displayed before logon.
- Apply GPOs to specific OUs containing computer accounts.
- Understand the difference between User Configuration and Computer Configuration policies.
- Refresh Group Policy settings using gpupdate /force.
- Verify applied policies using gpresult, rsop.msc, and Group Policy reports.
- Test policy behavior by logging in with different domain user accounts.

At the end of this lab, you will be able to create, configure, apply, and troubleshoot basic Group Policy settings for centralized management of domain users and computers.

Useful commands:
- ``gpupdate/force`` - Forces the Group Policy settings to be refreshed and reapplies all policy settings, even if they have not changed since the last update.
- ``gpresult /r`` - Displays a summary of the Group Policy settings applied to the current user and computer, including the applied GPOs.
- ``gpresult /h c:\temp\report.html`` - Generates an HTML report containing detailed information about the Group Policy settings applied to the user and computer.
- ``rsop.msc`` - Opens the Resultant Set of Policy (RSoP) console, which displays the effective Group Policy settings applied to the user and computer.

In **Group Policy Management**, go to ``Forest > Domains > <domain-name> > <domain> > Users``, right-click on ``HR_Users`` and click on **Link an Existing GPO**.

<img width="613" height="687" alt="image" src="https://github.com/user-attachments/assets/705313e9-530f-43e2-a32a-19e60f160afc" /><br>
