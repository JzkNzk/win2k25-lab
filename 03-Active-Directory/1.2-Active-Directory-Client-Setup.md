# Setting up your Windows 11 clients

## Goals

The goal of this lab is to configure Windows 11 client computers and join them to an existing Active Directory domain.

By completing this lab, you will learn how to:

- Configure a static IPv4 address and set the Domain Controller as the preferred DNS server.
- Change the computer name to follow your naming convention.
- Join a Windows 11 client to an Active Directory domain.
- Authenticate using domain Administrator credentials during the domain join process.
- Verify the network configuration using the `ipconfig /all` command.
- Confirm that the client computer appears in Active Directory Users and Computers.

At the end of this lab, you will have a Windows 11 client successfully joined to your Active Directory domain and ready for centralized management and further testing.

## Initial Windows 11 Active Directory setup

On your Windows 11 client, open **Network Connections**, go to your interface properties and set your IPv4 address.

Make sure to enter your Windows Server IP address as Preferred DNS server.

<img width="975" height="590" alt="image" src="https://github.com/user-attachments/assets/3dd4247a-3965-4e87-b131-e885bf5445a2" /><br>

Next, you have to set up your computer name. Open Windows settings and from the left menu select **System**.

<img width="975" height="491" alt="image" src="https://github.com/user-attachments/assets/b618b007-c877-4f50-9405-9b053d818f8a" /><br>

Open **About** section, scroll down a little until you see **Related links**. From there click on *Domain or workgroup* link.

<img width="975" height="643" alt="image" src="https://github.com/user-attachments/assets/3ce1a53c-24a8-4eff-9aba-75cabce4f355" /><br>

This will open **System Properties** windows. Click on the *Change...* button and in the new window enter your computer name and in the **Member of** section select *Domain* and enter your domain name.
After setting up your computer name and domain windows will prompt you to log-in. Use your Administrator credentials to join the domain.

<img width="975" height="587" alt="image" src="https://github.com/user-attachments/assets/c4425514-d6e7-430a-9605-d395b4ed7a53" /><br>

---

Once you join the domain restart your Windows 11 client.

To check if your client is configured properly, open **Terminal** or **PowerShell** and type in `ipconfig /all` command. This will show your client's name, domain and IP address.

<img width="975" height="545" alt="image" src="https://github.com/user-attachments/assets/5c3142e1-01f6-4f9b-b24e-198157fc6ac4" /><br>

---

To check if your pc joined the domain you can check new entry on your Active Directory server.

Switch to your server and from the **Server Manager** in the tools dropdown open **Active Directory Users and Computers**. Navigate into `<your.domain> > Computers`. You can see now your Windows 11 client in the list.
