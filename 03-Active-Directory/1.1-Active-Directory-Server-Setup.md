# Setting up your first Active Directory Server

## Goals

The goal of this lab is to introduce the installation and initial configuration of Active Directory Domain Services (AD DS) and the creation of a new Active Directory forest.

By completing this lab, you will learn how to:

- Configure basic Windows Server settings, including computer name, static IP address, DNS, and time zone.
- Install the Active Directory Domain Services (AD DS) role.
- Promote a Windows Server to a Domain Controller.
- Create a new Active Directory forest and configure its root domain.
- Configure Domain Controller options and the Directory Services Restore Mode (DSRM) password.
- Join a Windows Server to the newly created domain.
- Verify the Active Directory installation using PowerShell and DNS diagnostic commands.

At the end of this lab, you will have a functional Active Directory environment with a newly configured Domain Controller, ready for further administration and domain management.

## Installing AD DS roles and features

From **Server Manager**, open **Manage** dropdown and select *Add Roles and Features...*.

<img width="362" height="170" alt="image" src="https://github.com/user-attachments/assets/e7be25bc-0b1f-4f94-866e-fc1b79517d5d" /><br>

Once the installation is complete, open **Active Directory Domain Services Configuration Wizard**.

As a deployment operation, select *Add a new forest* and enter your Root domain name.

## Validating installation

Once you log back into your server check if the AD DS installation was successful.

Use the following commands:
- `nslookup <domain.name>` - used to resolve DNS
- `Get-Service adws, kdc, netlogon, dns, dfsr` - check AD related service status
- `Get-ADDomain` - check AD configuration
- `Get-ADForest` - check Forest configuration
