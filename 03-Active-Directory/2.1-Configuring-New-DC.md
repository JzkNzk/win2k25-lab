# New Domain Controller configuration

## Goals

The goal of this lab is to configure an additional Domain Controller in an existing Active Directory domain and verify that directory services and DNS are properly replicated.

By completing this lab, you will learn how to:

- Install the Active Directory Domain Services (AD DS) role on an additional Windows Server.
- Promote the server to a Domain Controller in an existing domain.
- Configure the new Domain Controller to replicate data from the primary Domain Controller.
- Understand the role of multiple Domain Controllers in an Active Directory environment.
- Verify Active Directory replication by checking the Organizational Unit structure and domain objects.
- Verify DNS configuration and confirm that both Domain Controllers are registered as name servers.
- Check the presence of the SYSVOL and NETLOGON shared folders.
- Verify the status of essential services, including NTDS, DNS, DFSR, KDC, and Netlogon.

At the end of this lab, you will have two functional Domain Controllers in the same Active Directory domain, providing directory service redundancy and replicated domain data.
